# A Fun Day in Paris（3D 動畫英語繪本）

情境素養導向的互動 3D 繪本，單一 HTML 檔（音檔與照片都已內嵌），用 Chrome／Edge 開啟。

- 線上網址：https://imacipadtw-lang.github.io/123456/picture-books/paris/
- 11 頁（封面＋9 個情境＋封底），可翻頁、拖曳 360° 旋轉，點閃亮的東西有隱藏驚喜
- 字幕模式：1 無字幕／2 英文字幕／3 中英字幕／4 跟著唸（收音評分，限 Chrome／Edge）
- 每頁一個小遊戲：餵飽泰迪、句子排排站、聽力射氣球、完美合照、找到警察、跟著指令走、真實照片大考驗、名畫擺拍
- 角色與口袋小精靈（Mochi、Bao、Puff）為原創設計；真實照片來自 Unsplash（Unsplash License）
- 語音：部分句子為真人錄音（CC BY-NC-ND 3.0，限非商業使用，未經修改），其餘標示「AI 語音」；來源與授權見頁尾「音檔來源與授權」
