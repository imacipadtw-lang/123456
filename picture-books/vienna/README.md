# Vienna, City of Music（3D 動畫英語繪本）

情境素養導向的互動 3D 繪本，單一 HTML 檔（音檔與照片都已內嵌），用 Chrome／Edge 開啟。

- 線上網址：https://imacipadtw-lang.github.io/123456/picture-books/vienna/
- 11 頁（封面＋9 個情境＋封底），可翻頁、拖曳 360° 旋轉，點閃亮的東西有隱藏驚喜
- 字幕模式：1 無字幕／2 英文字幕／3 中英字幕／4 跟著唸（收音評分，限 Chrome／Edge）
- 每頁一個小遊戲：彈奏莫札特、句子排排站、交通工具大考驗、聽力射氣球、誰是誰、休閒活動配對、轉台給貝多芬看、全壘打大挑戰
- 角色（含 Q 版莫札特、貝多芬）與口袋小精靈為原創設計；真實照片來自 Unsplash（Unsplash License）
- 語音：3 句為真人錄音（CC BY-NC-ND 3.0，限非商業使用，未經修改），其餘標示「AI 語音」；來源與授權見頁尾「音檔來源與授權」

## 方塊冒險遊戲：Vienna Block Quest

- 線上網址：https://imacipadtw-lang.github.io/123456/picture-books/vienna/block-quest/
- 方塊世界（麥塊風格，原創材質與角色）：挖方塊、放方塊、蓋歌劇院、搭電車、敲音符方塊、合成電視、打全壘打，8 個任務對應繪本 18 句
- 完成任務會收進「句子本」，可以重聽；進度自動存在瀏覽器
