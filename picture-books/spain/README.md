# Hola, Barcelona!（3D 動畫英語繪本・五年級）

情境素養導向的互動 3D 繪本，單一 HTML 檔（音檔與照片都已內嵌），用 Chrome／Edge 開啟。

- 線上網址：https://imacipadtw-lang.github.io/123456/picture-books/spain/
- 11 頁（封面＋9 個情境＋封底），課文 17 句依序出現；可翻頁、拖曳 360° 旋轉，點閃亮的東西有隱藏驚喜
- 字幕模式：1 無字幕／2 英文字幕／3 中英字幕／4 跟著唸（收音評分，限 Chrome／Edge）
- 每頁一個小遊戲：句子排排站、星期排排站、真實照片大考驗、世界打招呼、PK 大賽、Is it …? 快問快答、聽力射氣球、大 G 小 o 加油團
- 角色與口袋小精靈為原創設計；真實照片（聖家堂、奎爾公園、諾坎普球場、足球）來自 Unsplash（Unsplash License）
- 語音：4 句含真人錄音（CC BY-NC-ND 3.0，限非商業使用，未經修改），其餘標示「AI 語音」，是電腦合成，不是真人錄音；來源與授權見頁尾「音檔來源與授權」
