# 2027 關西慢旅

1/23–2/4 神戶、大阪、和歌山的行程網站。

## 檔案

- `index.html`：網站本體（版面和功能）
- `trip-data.js`：所有行程資料。**要改行程只改這個檔案**

## 怎麼改行程

1. 在 GitHub 打開 `trip-data.js`，按右上角的鉛筆圖示。
2. 找到要改的那天（例如 `date: "2027-01-27"`），照旁邊的格式修改或新增一行。
3. 按「Commit changes」，約 1 分鐘後網站就會更新。

也可以直接在網站上按「＋ 新增行程」。網站上新增的內容只存在那支手機，要讓老公也看到，就到「待辦 > 備份我新增的行程」按複製，傳給 Claude 幫你加進 `trip-data.js`。

## 隱私

這個儲存庫是公開的，所以沒有放訂位代號、訂單編號和姓名。這些請填在網站「航班」頁最下面的欄位，只會存在自己的手機。
